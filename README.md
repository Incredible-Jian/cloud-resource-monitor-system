🔍 Cloud Resource Monitoring & Anomaly Access Control System
A full-stack enterprise monitoring system built with Spring Boot. It implements the complete pipeline of data collection, storage, computation, visualization, and alerting.

✨ Core Features:
• Real-time monitoring of cloud resources (CPU, Memory, Disk, Network).
• Intelligent anomaly detection and automatic IP blocking with a rule engine.
• LSTM-based time-series forecasting for resource capacity prediction.
• Visual dashboard for operational insights and alert management (mail/dingtalk).

🛠 Tech Stack: Spring Boot | MyBatis | MySQL | Redis | Docker | Rule Engine (Drools) | LSTM
